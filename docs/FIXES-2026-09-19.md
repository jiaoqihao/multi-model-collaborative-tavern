# 生成可靠性修复 · 2026-09-19

## 已修复

1. **经济模式记忆长度冲突**：卡片改为受限的规则整理视图，单条长内容标记为节选，保留前后片段；完整事件与角色原始记忆仍保存。按实际 JSON 序列化长度控制总量，超容量时优先保留待办，再保留近期事实与主观判断，并提示条目未全部收录。
2. **长线索无法可靠关闭**：卡片待办绑定稳定线索 ID；关闭一条线索不误删同前缀的另一条。仅线索变化也会更新相关角色卡，完整线索描述不截断。模型记忆阶段也收到按角色过滤的线索变更。
3. **输出协议缺失约束**：展开 Zod 默认字段、枚举与整数范围，剧情线索的 action、characterIds、sourceEventIndex 得到完整描述。程序协议升级至 v3，旧缓存指纹不会继续使用。
4. **无效角色引用进入缓存**：导演、裁决、复核阶段在保存缓存前验证角色 ID、重复分配／状态变更、线索索引和增量字段。`player` 不是角色 ID；玩家可见性由 visibleToPlayer 单独表示。错误会进入已有的一次结构纠正重试，旧无效缓存会跳过，持续失败仍不会保存剧情。
5. **导演越权指导**：角色行动模式强制清空 direction，避免导演用幕后指令要求角色拒答等；显式导演模式仍保留指导。visible 的提示词禁止提前编写角色回应。此项不代表能完全自动识别所有语义越界。
6. **复核缺少证据**：精细模式复核获得实际信息分发、角色台词和动作意图，不再只凭候选事件判断；不传入角色内心字段。
